# Hasil Task 9: Verifikasi End-to-End Aplikasi Tauri

Tanggal: 2026-08-05
Dijalankan oleh human partner dengan langganannya sendiri.

Perintah: `cd app && export PATH="$HOME/.cargo/bin:$PATH" && npm run tauri dev`

Peluncuran bersih: Vite siap 196 ms, cargo build selesai, proses `app` berjalan,
tidak ada error maupun panic di keluaran.

## Terverifikasi

**1. Jendela terbuka dan tersambung.** Status tidak tertahan di "Menyambungkan…".

Ini menutup blocker pertama dari final review: guard StrictMode di `App.tsx` yang
membuang hasil koneksi, sehingga jendela akan tertahan selamanya dengan input mati —
dan kegagalan sungguhan pun tampil identik tanpa pesan. Perbaikannya bekerja di jendela
sungguhan, bukan hanya di test.

**2. Teks agen muncul.** Balasan agen terlihat di panel chat.

Ini menutup blocker kedua: `events.rs` memancarkan `TEXT_MESSAGE_CHUNK` dan
`THINKING_TEXT_MESSAGE_CONTENT`, dua nama yang **tidak punya `case` sama sekali** di
`StreamProcessor` TanStack, sehingga setiap kata asisten dibuang diam-diam. 72 test Rust
dan 13 test frontend semuanya hijau dengan bug itu di dalamnya.

**5. Tidak ada proses bocor.** Setelah jendela ditutup dan `tauri dev` keluar dengan
exit 0, `pgrep` untuk `claude-agent-acp`, `codex-acp`, `midscene-mcp`, `target/debug/app`,
dan Chrome otomasi semuanya kosong.

Ini sekaligus mengonfirmasi temuan final review: `tauri::App::run` berakhir lewat
`std::process::exit`, jadi `ChildGuard` milik crate tidak pernah drop — kebersihan
bergantung pada `claude-agent-acp` yang keluar saat stdin EOF. Untuk agen itu, terbukti
bekerja. `codex-acp` adalah peluncur wrapper dan merupakan kasus yang komentar crate
sebut tidak tercakup; hook keluar tetap perlu (residu nomor 2).

## Belum diverifikasi

**3. Dialog izin muncul dan menyebut nama tool.**
**4. Chrome terbuka, assertion lulus, sesi tertutup.**

Keduanya butuh prompt yang benar-benar memanggil tool Midscene. Tidak dijalankan pada
sesi ini.

Konsekuensinya: rantai penuh `agen → permission_gate → event Tauri → PermissionDialog →
answer_permission` masih belum pernah dijalankan utuh. Sisi Rust terbukti di atas kabel
sungguhan; sisi React hanya terbukti lewat test komponen buangan yang dibuat reviewer
lalu dihapus. Ini yang paling layak diperiksa pada pemakaian berikutnya.

Juga belum terlihat: apakah perbaikan duplikasi teks bekerja pada pola
`teks → tool call → teks`, yang hanya muncul bila ada tool call sungguhan.

## Pengamatan pengguna

Tampilannya mentah. Akar masalahnya: agen memancarkan markdown dan aplikasi merendernya
sebagai `<p>` polos, karena komponen shadcn `typeset` tidak ada di registry saat 2a
dikerjakan. Ditangani di rencana 2b-3.

Pengguna juga menemukan celah yang lebih besar: hasil yang diproduksi aplikasi tidak
bisa dilihat dari aplikasi, dan tidak ada kelanjutan sesi. Keduanya dirancang di
`2026-08-05-aplikasi-tauri-2b-design.md`.
